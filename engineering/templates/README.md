# Templates (V0 foundation)

Plain Markdown templates for humans and agents. V0 has **no rendering engine**:
placeholders use `<angle-bracket>` notation and are filled in by hand.
Automated rendering (and a templating dependency) will be introduced only when a
real consumer exists (e.g. prompt/document generation in later versions).

- `adr.md` — Architecture Decision Record
- `sprint.md` — sprint record (project documentation format)
- `task.md` — task contract (fields from RF-009)
